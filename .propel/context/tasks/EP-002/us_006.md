## Story

**As a** platform engineer,
**I want** the Supervisor Agent to execute sub-agents (Intent, Retrieval, Compression, Routing) in the correct sequence,
**So that** each context request is fully processed with no steps skipped.

## Acceptance Criteria

- [ ] Supervisor follows the defined pipeline: Intent → Retrieval → (Governance) → Compression → Routing
- [ ] Each sub-agent receives state output from the previous node as input
- [ ] Pipeline execution is logged at entry and exit of every node with timing
- [ ] A failed node causes the pipeline to transition to `failed` state with structured error
- [ ] Conditional edges route correctly (e.g., skip Compression if token budget already met)
- [ ] End-to-end pipeline execution completes within p95 = 3 s for a standard request
