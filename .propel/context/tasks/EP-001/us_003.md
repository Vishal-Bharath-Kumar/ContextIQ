## Story

**As a** software developer using an AI coding assistant,
**I want** to invoke a ContextIQ tool (e.g., `get_context`, `search_knowledge`) and receive a structured response,
**So that** my AI assistant can incorporate enterprise context into its answers automatically.

## Acceptance Criteria

- [ ] MCP `tools/call` dispatches request to the agent pipeline
- [ ] Successful tool calls return results within the platform SLA (p95 < 3 s)
- [ ] Response is JSON-serializable and conforms to the tool's declared output schema
- [ ] Tool errors return a structured error payload (code + message) without crashing the session
- [ ] Concurrent tool calls from the same session are handled independently without state bleed
- [ ] Each tool call is traced end-to-end with a correlation ID visible in Jaeger
