## Story

**As a** platform engineer,
**I want** a well-documented `BaseConnector` abstract class with a defined interface,
**So that** my team (and third-party vendors) can implement new connectors without modifying the core platform.

## Acceptance Criteria

- [ ] `BaseConnector` defines abstract methods: `authenticate()`, `fetch(query, filters)`, `sync()`, `health_check()`
- [ ] Connector developers implement a single Python class that extends `BaseConnector`
- [ ] Connectors are auto-discovered at startup via Python entry-point registration
- [ ] `health_check()` method is polled by the platform every 30 s; unhealthy connectors are disabled automatically
- [ ] A developer guide and working example connector are available in the repository
- [ ] Unit test scaffold for connectors is included in the SDK
