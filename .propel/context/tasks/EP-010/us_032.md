## Story

**As a** security officer,
**I want** Open Policy Agent to evaluate whether a user is authorized to access each retrieved document based on their roles and the document's classification,
**So that** users never receive context from knowledge sources they are not permitted to access.

## Acceptance Criteria

- [ ] OPA policy bundle is loaded at startup from a versioned policy repository
- [ ] Governance Agent calls OPA `data.contextiq.authz.allow` for each context chunk with: `user_roles`, `tenant_id`, `source_id`, `classification_label`
- [ ] Chunks denied by OPA are filtered from the context before model submission
- [ ] Policy decision (`allow`/`deny`) and rationale are recorded in the execution trace
- [ ] OPA evaluation completes within 50 ms per chunk (inline evaluation, not remote call)
- [ ] Policy hot-reload is supported: updated bundles take effect within 60 s without platform restart
- [ ] Policy violation count is exposed as Prometheus metric `governance_policy_denials_total`
