## Story

**As a** security officer,
**I want** a UI to view, author, activate, and roll back OPA governance policies,
**So that** I can manage access control rules without needing Rego expertise or API access.

## Acceptance Criteria

- [ ] Policy list page shows all policies with version history, active version badge, author, and activation timestamp
- [ ] Policy editor includes a syntax-highlighted Rego code editor with inline OPA validation (parse errors shown immediately)
- [ ] "Preview Impact" button simulates the policy against the last 100 context requests and shows projected allow/deny statistics
- [ ] "Activate" button promotes the current draft to active; confirmation dialog is shown
- [ ] "Rollback" dropdown allows one-click restore of a previous version
- [ ] All policy changes are recorded in the audit trail with user ID and timestamp
- [ ] Policy UI is accessible to users with `SECURITY_OFFICER` or `ADMIN` role only
