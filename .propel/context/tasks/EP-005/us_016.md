## Story

**As a** software developer,
**I want** near-duplicate content from different sources to be merged into a single representative chunk,
**So that** my AI assistant does not waste tokens processing the same information multiple times.

## Acceptance Criteria

- [ ] Semantic deduplicator computes cosine similarity between all remaining chunks
- [ ] Chunk pairs with similarity ≥ 0.92 are merged; the higher-scored chunk is retained
- [ ] Merge operation records which source IDs were consolidated in execution state
- [ ] Semantic deduplication completes within 300 ms for a set of 50 chunks
- [ ] Merged context token count is reduced by at least 15% on redundant multi-source retrievals
- [ ] Similarity threshold is configurable via admin panel
