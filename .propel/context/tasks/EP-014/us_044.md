## Story

**As an** auditor,
**I want** every administrative action (policy change, connector creation, user role change, model activation) to be recorded in a tamper-evident audit log,
**So that** I can prove to regulators what changes were made, by whom, and when.

## Acceptance Criteria

- [ ] Audit log entry is written on every mutating Admin API call with: `user_id`, `action`, `resource_type`, `resource_id`, `before_state`, `after_state`, `timestamp`, `ip_address`
- [ ] Audit log is stored in PostgreSQL with row-level immutability (no UPDATE or DELETE allowed on audit table)
- [ ] Audit log is also archived to MinIO daily as JSON for long-term retention (3 years minimum)
- [ ] Audit log query API `GET /v1/audit-log` supports filtering by: user, action type, resource, and date range
- [ ] Audit log viewer is accessible in Admin Portal for users with `AUDITOR` or `ADMIN` role
- [ ] Audit log integrity can be verified by re-hashing entries against a stored SHA-256 chain hash
