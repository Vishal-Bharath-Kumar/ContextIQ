## Story

**As a** software developer,
**I want** ContextIQ to search enterprise knowledge using both vector similarity and keyword matching,
**So that** I receive precise results even when my prompt uses terminology that does not match exact document wording.

## Acceptance Criteria

- [ ] Retrieval Engine executes Qdrant ANN vector search and OpenSearch BM25 keyword search in parallel
- [ ] Results from both search paths are merged using Reciprocal Rank Fusion (RRF)
- [ ] Merged result set returns the top-K documents (configurable, default K=20)
- [ ] Hybrid search completes within p95 = 1 s for a corpus of 1 million documents
- [ ] Each result includes: `source_id`, `content`, `score`, `metadata` (file path, timestamp, author)
- [ ] Search results are stored in execution state for downstream compression
