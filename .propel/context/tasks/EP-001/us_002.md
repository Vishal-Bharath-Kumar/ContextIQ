## Story

**As a** software developer using an AI coding assistant,
**I want** my AI assistant to list all available ContextIQ tools,
**So that** the assistant can decide which tools to invoke for a given prompt.

## Acceptance Criteria

- [ ] MCP `tools/list` response returns all registered tool definitions
- [ ] Each tool definition includes `name`, `description`, and `inputSchema`
- [ ] Tool list is returned within 200 ms for up to 50 registered tools
- [ ] Tool list is cached; changes propagate within 30 seconds of registration update
- [ ] Inactive or disabled tools are excluded from the list
- [ ] OTel span emitted for each `tools/list` call
