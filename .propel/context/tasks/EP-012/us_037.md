## Story

**As an** engineering manager,
**I want** a dashboard showing daily LLM token consumption, cost per request, and compression savings per team,
**So that** I can track AI spend trends and demonstrate ROI from the Compression Engine.

## Acceptance Criteria

- [ ] Every LLM call records: `model_id`, `prompt_tokens`, `completion_tokens`, `cost_usd`, `user_id`, `team_id` in Langfuse
- [ ] Compression Agent records: `tokens_before_compression`, `tokens_after_compression` per request
- [ ] Grafana "AI Cost & Efficiency" dashboard includes: daily cost by model, cost per user/team, compression savings %, and token budget utilization
- [ ] Cost data is queryable via Langfuse API for export to BI tools
- [ ] Data retention for cost records: minimum 12 months
- [ ] Dashboard filters by: date range, team, model, and intent type
