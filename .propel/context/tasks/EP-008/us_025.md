## Story

**As an** enterprise administrator,
**I want** to register and configure knowledge sources (repositories, spaces, projects) through the Admin API,
**So that** ContextIQ indexes only the approved and relevant enterprise content.

## Acceptance Criteria

- [ ] Admin API `POST /v1/knowledge-sources` creates a new source with: `connector_type`, `credentials_vault_path`, `scope`, `sync_schedule`, `token_budget_weight`
- [ ] Source configuration is stored in PostgreSQL; credentials are stored in Vault (never in DB)
- [ ] `GET /v1/knowledge-sources` returns all sources with status, last sync timestamp, and document count
- [ ] Source can be toggled active/inactive without deletion
- [ ] Invalid Vault paths return a descriptive 400 error at creation time
- [ ] Source creation event is emitted to Kafka for downstream indexing service to pick up
