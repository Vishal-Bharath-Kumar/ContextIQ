## Story

**As a** software developer,
**I want** ContextIQ to search and retrieve Confluence pages relevant to my prompt,
**So that** my AI assistant can reference architecture decisions, runbooks, and onboarding guides.

## Acceptance Criteria

- [ ] Confluence Connector authenticates using an API token stored in Vault
- [ ] `fetch()` uses the Confluence CQL Search API to find pages matching the context query within configured spaces
- [ ] Results include: page title, content excerpt, space key, URL, last-modified timestamp, and author
- [ ] Connector supports Cloud and Data Center Confluence deployments via configurable base URL
- [ ] `sync()` uses the `lastModified` filter to fetch only updated pages since the last sync
- [ ] Pages exceeding 10 000 tokens are chunked at natural section boundaries before indexing
- [ ] Connector returns results within 2 s
