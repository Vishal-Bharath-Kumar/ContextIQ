## Story

**As a** platform engineer,
**I want** a new LangGraph StateGraph execution context created for each incoming tool call,
**So that** every context request has isolated, traceable state throughout its lifecycle.

## Acceptance Criteria

- [ ] A unique `request_id` (UUID v4) is generated and attached to the StateGraph instance
- [ ] Initial state captures: `request_id`, `user_id`, `prompt`, `timestamp`, `tool_name`
- [ ] State is persisted to Redis with a 1-hour TTL for mid-flight recovery
- [ ] State transitions (pending → running → complete/failed) are recorded as immutable events
- [ ] Concurrent requests from the same user are executed in independent graph instances
- [ ] State initialization completes within 50 ms
