## Story

**As a** DevOps/SRE,
**I want** ContextIQ to retrieve open incidents from Jira and recent alert annotations from Grafana,
**So that** my AI assistant has real-time operational context when I investigate platform issues.

## Acceptance Criteria

- [ ] Jira Connector authenticates via API token and retrieves issues by JQL query (e.g., `project = OPS AND status != Done`)
- [ ] Grafana Connector authenticates via service account token and retrieves dashboard annotations and alert history via HTTP API
- [ ] Jira results include: issue key, summary, status, priority, assignee, and description excerpt
- [ ] Grafana results include: alert name, state, message, and timestamp
- [ ] Both connectors are independently configurable (separate credentials, separate enable/disable toggle)
- [ ] Both connectors complete `fetch()` within 3 s
- [ ] Connector credentials are stored in Vault, never in database plaintext
