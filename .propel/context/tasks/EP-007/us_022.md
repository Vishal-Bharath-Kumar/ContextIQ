## Story

**As a** software developer,
**I want** ContextIQ to retrieve relevant code snippets, README files, and recent commit history from GitHub,
**So that** my AI assistant can reason about the actual codebase state when answering my questions.

## Acceptance Criteria

- [ ] GitHub Connector authenticates using a PAT or GitHub App installation token stored in Vault
- [ ] `fetch()` queries the GitHub Search API for code matching the context query within configured repos
- [ ] Results include: file path, content excerpt, repository, branch, last commit SHA, and timestamp
- [ ] Connector fetches commits from the last 30 days by default (configurable)
- [ ] Incremental `sync()` uses `since` parameter to fetch only changes since last sync timestamp
- [ ] GitHub API rate-limit is handled with exponential backoff and a 429 metric emitted
- [ ] Connector returns results within 2 s for queries returning ≤ 50 files
