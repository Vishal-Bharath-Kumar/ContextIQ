## Story

**As an** enterprise administrator,
**I want** a web UI to register, configure, enable/disable, and test connectors,
**So that** I can manage knowledge source integrations without using REST APIs or CLI tools.

## Acceptance Criteria

- [ ] Connector list page shows all connectors with status badge (active/inactive/error), last sync timestamp, and document count
- [ ] "Add Connector" wizard supports: connector type selection, credential entry (masked, stored in Vault), scope configuration, and sync schedule input
- [ ] "Test Connection" button triggers a live `health_check()` call and shows result inline
- [ ] Connector can be enabled/disabled with a toggle (takes effect within 30 s)
- [ ] Connector configuration changes are logged in the audit trail
- [ ] Admin Portal is a React SPA served from its own Kubernetes deployment
- [ ] UI is accessible at WCAG 2.1 AA standard
