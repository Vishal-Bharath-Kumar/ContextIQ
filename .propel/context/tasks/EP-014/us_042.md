## Story

**As a** platform engineer,
**I want** every API endpoint to enforce RBAC based on the user's assigned roles,
**So that** developers can only call context tools, admins can manage configurations, and auditors can only read traces.

## Acceptance Criteria

- [ ] Seven roles are defined and enforced: `DEVELOPER`, `PLATFORM_ENGINEER`, `DEVOPS_SRE`, `ADMIN`, `SECURITY_OFFICER`, `MANAGER`, `AUDITOR`
- [ ] Role-to-permission matrix is documented and enforced in the platform access control layer
- [ ] API endpoints return HTTP 403 when the authenticated user lacks the required permission
- [ ] User roles are extracted from the Keycloak JWT `roles` claim on every request
- [ ] Role changes in Keycloak propagate to the platform within the JWT TTL (default 5 min)
- [ ] RBAC enforcement is unit-tested for each role and each protected endpoint
