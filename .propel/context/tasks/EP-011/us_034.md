## Story

**As an** auditor,
**I want** ContextIQ to create a complete, immutable execution trace for every AI context request,
**So that** I can review exactly what context was assembled and sent to an LLM for any past request.

## Acceptance Criteria

- [ ] Execution trace is written to MinIO as an immutable JSON object on request completion
- [ ] Trace includes: `request_id`, `user_id`, `timestamp`, `prompt`, `intent`, `execution_plan`, `retrieved_chunks` (pre- and post-compression), `governance_decisions`, `model_selected`, `response_summary`
- [ ] Trace object is write-once; updates create a new version, not overwrites
- [ ] Trace is also indexed in PostgreSQL for search (by `request_id`, `user_id`, `timestamp`, `intent`)
- [ ] Traces are retained for a minimum of 90 days (configurable; default = 1 year)
- [ ] Trace writes complete asynchronously; they must not add latency to the main request path
