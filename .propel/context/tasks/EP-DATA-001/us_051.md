## Story

**As a** platform engineer,
**I want** all five specialized data stores deployed to Kubernetes with production-grade configuration,
**So that** the knowledge retrieval, graph, and object storage capabilities are available for the agent pipeline.

## Acceptance Criteria

- [ ] **Qdrant:** Deployed in cluster mode (3 nodes), collection `contextiq_embeddings` created with `text-embedding-3-small` vector dimension (1536), cosine distance metric
- [ ] **Neo4j:** Deployed as Causal Cluster (3 cores), graph schema constraints and indexes created for `Service`, `Repository`, `Developer`, `Incident` nodes
- [ ] **OpenSearch:** Deployed as 3-node cluster, index `contextiq_documents` created with `bm25` analyzer, field mappings for `content`, `source_id`, `metadata`, `indexed_at`
- [ ] **Redis:** Deployed as Redis Sentinel HA (1 primary + 2 replicas), keyspace notifications enabled for cache invalidation events
- [ ] **MinIO:** Deployed with 4 nodes in distributed mode, bucket `contextiq-traces` created with versioning and lifecycle rules (90-day transition to cold tier, 1-year expiry)
- [ ] All stores have Vault-managed credentials injected via sidecar
- [ ] Health check endpoints for all stores are monitored by Prometheus ServiceMonitors
