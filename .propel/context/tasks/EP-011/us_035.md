## Story

**As an** auditor or engineering manager,
**I want** to search and replay past AI execution traces in the Admin Portal,
**So that** I can investigate anomalies, verify governance decisions, and demonstrate compliance during audits.

## Acceptance Criteria

- [ ] Replay Explorer UI lists executions searchable by: `user_id`, `date range`, `intent type`, `model used`, `governance decision`
- [ ] Each trace row links to a detail view showing a step-by-step timeline of the pipeline
- [ ] Detail view renders: intent classification, retrieved source list with relevance scores, compression delta (before/after token counts), governance decisions (allows/denies), selected model, and response summary
- [ ] Replay read access is restricted to users with `AUDITOR` or `ADMIN` role
- [ ] Traces load within 2 s for requests up to 1 year old
- [ ] Trace export to JSON is available for download from the detail view
