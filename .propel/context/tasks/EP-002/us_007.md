## Story

**As a** software developer,
**I want** ContextIQ to fetch from multiple knowledge sources (GitHub, Confluence, Jira, Grafana) concurrently,
**So that** the overall response latency is bounded by the slowest source, not the sum of all sources.

## Acceptance Criteria

- [ ] Retrieval Agent dispatches each enabled connector using `asyncio.gather`
- [ ] All connectors execute in parallel within the same retrieval step
- [ ] Per-connector timeout is enforced (configurable, default 5 s)
- [ ] Individual connector results are aggregated into a unified results list
- [ ] A connector timing out does not block results from other connectors
- [ ] Parallelism is confirmed by observing concurrent OTel spans in Jaeger for a request
