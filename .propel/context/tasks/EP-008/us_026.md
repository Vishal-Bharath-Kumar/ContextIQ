## Story

**As an** enterprise administrator,
**I want** each knowledge source to sync on a configurable cron schedule,
**So that** the indexed content stays up to date without requiring manual intervention.

## Acceptance Criteria

- [ ] Sync scheduler reads cron expressions from source configuration (e.g., `*/30 * * * *`)
- [ ] On schedule trigger, the connector's `sync()` method is called with `since = last_sync_timestamp`
- [ ] Sync job status (running / succeeded / failed) is recorded in PostgreSQL
- [ ] Failed sync jobs are retried up to 3 times with exponential backoff
- [ ] A Kafka event `knowledge.source.synced` is emitted on successful sync completion
- [ ] Admin can trigger an on-demand full sync via `POST /v1/knowledge-sources/{id}/sync`
- [ ] Sync duration and document count delta are emitted as Prometheus metrics
