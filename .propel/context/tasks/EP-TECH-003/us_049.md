## Story

**As a** platform engineer,
**I want** every pull request and main-branch push to automatically run linting, unit tests, security scans, container image builds, and ArgoCD deployments,
**So that** code quality and security gates are enforced continuously without manual steps.

## Acceptance Criteria

- [ ] GitHub Actions workflow runs on every PR: ruff lint, mypy type-check, pytest (unit + integration), Trivy image scan, OWASP Dependency-Check
- [ ] Build job creates multi-arch Docker images (amd64 + arm64) and pushes to GitHub Container Registry with image tag = `git-sha`
- [ ] Failed lint, test, or security scan blocks PR merge (required status check)
- [ ] On merge to `main`, ArgoCD sync is triggered automatically (GitOps push-to-deploy)
- [ ] Deployment to staging completes within 10 minutes of merge
- [ ] Promotion to production requires a manual approval step in the GitHub Actions environment
- [ ] Pipeline duration target: PR checks < 8 min, full deploy pipeline < 15 min
