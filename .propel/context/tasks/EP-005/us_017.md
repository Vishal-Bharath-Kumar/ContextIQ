## Story

**As a** software developer,
**I want** long context chunks (runbooks, lengthy Confluence pages) to be summarized before they are injected into my AI prompt,
**So that** the key information is retained while staying within the model's context window limit.

## Acceptance Criteria

- [ ] Chunks exceeding a configurable token threshold (default 500 tokens) are submitted for LLM summarization
- [ ] Summarization uses a lightweight model (configured via Dynamic Model Router) to minimize cost
- [ ] Summary retains all named entities, code identifiers, error codes, and action items from the original
- [ ] Summarized chunks are labeled with a `compressed: true` flag in the context payload
- [ ] Summarization reduces average chunk token count by 60% while retaining > 90% of key facts (validated by eval harness)
- [ ] LLM summarization cost per request is tracked in Langfuse
