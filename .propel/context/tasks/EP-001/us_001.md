## Story

**As a** software developer using an AI coding assistant (Cursor, GitHub Copilot, Claude Code),
**I want** my AI assistant to connect to the ContextIQ MCP endpoint,
**So that** I can access enterprise knowledge from within my existing AI workflow without switching tools.

## Acceptance Criteria

- [ ] FastMCP server starts and listens on the configured MCP endpoint path
- [ ] AI assistants can establish a connection using SSE transport
- [ ] AI assistants can establish a connection using WebSocket transport
- [ ] Endpoint returns a valid MCP server info response on `initialize`
- [ ] Connection is refused when the endpoint is unavailable (circuit open)
- [ ] OTel span emitted per connection attempt with status and latency
