## Story

**As a** platform engineer,
**I want** to register LLM models with their capability profiles (context window, cost per token, latency tier, modalities),
**So that** the Dynamic Model Router has accurate metadata to make optimal routing decisions.

## Acceptance Criteria

- [ ] Admin API endpoint `POST /v1/models` accepts a model registration payload
- [ ] Registration payload includes: `model_id`, `provider`, `context_window`, `cost_per_1k_tokens`, `latency_tier`, `capabilities[]`
- [ ] Registered models are stored in PostgreSQL and cached in Redis
- [ ] Duplicate `model_id` registration returns HTTP 409
- [ ] Model list endpoint `GET /v1/models` returns all active models sorted by cost ASC
- [ ] Model registry changes take effect within 30 seconds via cache invalidation event
