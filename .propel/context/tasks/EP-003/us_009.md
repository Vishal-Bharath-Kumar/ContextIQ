## Story

**As a** software developer,
**I want** ContextIQ to automatically detect the intent of my prompt (debugging, code generation, documentation lookup, etc.),
**So that** only the most relevant knowledge sources are queried and irrelevant context is excluded.

## Acceptance Criteria

- [ ] Intent classifier identifies at least 8 intent types: debugging, code-gen, architecture, docs, incident, metrics, code-review, general
- [ ] Classification confidence score (0–1) is stored in execution state
- [ ] Classification latency < 500 ms for prompts up to 2 000 tokens
- [ ] Intent type drives source selection (e.g., "incident" targets Grafana + Jira)
- [ ] Low-confidence results (< 0.6) are flagged for fallback to multi-source retrieval
- [ ] Intent label and score are emitted as OTel span attributes
