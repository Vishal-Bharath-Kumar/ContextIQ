## Description

Implement the configurable boilerplate detection system: a named regex rule registry loaded from settings, and a `BoilerplateDetector` that tests each chunk's content against all active rules. A chunk is classified as boilerplate when any rule matches. Rules cover common enterprise patterns (SPDX license headers, auto-generated file warnings, Maven/Gradle build artefacts) and are user-extensible without code changes.

**`BoilerplateRule` model:**

```python
# src/compression/boilerplate/rules.py
import re
from pydantic import BaseModel, field_validator

class BoilerplateRule(BaseModel):
    name:        str         # human-readable rule identifier, e.g. "spdx_license_header"
    pattern:     str         # regex pattern tested against chunk content
    description: str = ""
    enabled:     bool = True

    @field_validator("pattern")
    @classmethod
    def pattern_compiles(cls, v: str) -> str:
        re.compile(v, re.IGNORECASE | re.MULTILINE)   # raises re.error on invalid regex
        return v
```

**`BoilerplateDetector`:**

```python
# src/compression/boilerplate/detector.py
import re
from src.compression.boilerplate.rules import BoilerplateRule, DEFAULT_RULES
from src.retrieval.schemas.retrieved_chunk import RetrievedChunk
from src.compression.schemas.removed_chunk  import RemovedChunk, RemovalReason

class BoilerplateDetector:
    def __init__(self, rules: list[BoilerplateRule] | None = None) -> None:
        active = [r for r in (rules or DEFAULT_RULES) if r.enabled]
        # Pre-compile all patterns once at construction time
        self._compiled: list[tuple[str, re.Pattern[str]]] = [
            (rule.name, re.compile(rule.pattern, re.IGNORECASE | re.MULTILINE))
            for rule in active
        ]

    def matching_rule(self, content: str) -> str | None:
        """Return the name of the first matching rule, or None."""
        for rule_name, pattern in self._compiled:
            if pattern.search(content):
                return rule_name
        return None

    def filter(
        self,
        chunks: list[RetrievedChunk],
    ) -> tuple[list[RetrievedChunk], list[RemovedChunk]]:
        kept:    list[RetrievedChunk] = []
        removed: list[RemovedChunk]   = []
        for chunk in chunks:
            rule_name = self.matching_rule(chunk.content)
            if rule_name:
                removed.append(RemovedChunk(
                    chunk_id         = chunk.chunk_id,
                    source_id        = chunk.source_id,
                    reason           = RemovalReason.BOILERPLATE,
                    boilerplate_rule = rule_name,
                    original_content = chunk.content,
                ))
            else:
                kept.append(chunk)
        return kept, removed
```

**Runtime rule extension via settings:**

```python
# src/compression/boilerplate/settings.py
from pydantic_settings import BaseSettings

class BoilerplateSettings(BaseSettings):
    """Additional regex rules loaded from environment — one per line, pipe-separated.

    Format: BOILERPLATE_EXTRA_RULES=<name>|<pattern>;<name>|<pattern>
    Example: BOILERPLATE_EXTRA_RULES=internal_header|ACME CORP CONFIDENTIAL
    """
    boilerplate_extra_rules: str = ""
    boilerplate_disabled_rules: str = ""   # comma-separated rule names to disable

    model_config = SettingsConfigDict(env_file=".env")

    def get_rules(self) -> list[BoilerplateRule]:
        rules = list(DEFAULT_RULES)
        disabled = {r.strip() for r in self.boilerplate_disabled_rules.split(",") if r.strip()}
        rules = [r.model_copy(update={"enabled": r.name not in disabled}) for r in rules]
        for entry in self.boilerplate_extra_rules.split(";"):
            if "|" in entry:
                name, pattern = entry.split("|", maxsplit=1)
                rules.append(BoilerplateRule(name=name.strip(), pattern=pattern.strip()))
        return rules
```

## Acceptance Criteria

- [ ] A chunk containing `"SPDX-License-Identifier: MIT"` is matched by the `spdx_license_header` rule
- [ ] A chunk containing `"// This file was auto-generated"` is matched by the `auto_generated_warning` rule
- [ ] A chunk with no boilerplate passes through unmodified (`matching_rule` returns `None`)
- [ ] `RemovedChunk.boilerplate_rule` contains the name of the matching rule
- [ ] `BOILERPLATE_EXTRA_RULES=my_rule|ACME CORP CONFIDENTIAL` adds the rule at startup
- [ ] `BOILERPLATE_DISABLED_RULES=maven_build_output` disables that rule without removing it from the registry
- [ ] All regex patterns are pre-compiled at `BoilerplateDetector.__init__` — no `re.compile` inside the hot loop
