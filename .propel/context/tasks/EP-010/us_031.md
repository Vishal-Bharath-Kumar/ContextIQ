## Story

**As a** security officer,
**I want** ContextIQ to scan all assembled context for secrets (API keys, passwords, tokens) and PII (emails, names, SSNs) before it is sent to an LLM,
**So that** sensitive enterprise data is never inadvertently leaked to an AI provider.

## Acceptance Criteria

- [ ] Governance Agent runs as a mandatory pipeline node after compression and before model routing
- [ ] Detector identifies patterns: AWS/GCP/Azure keys, GitHub PATs, email addresses, credit card numbers, phone numbers, national IDs
- [ ] Each detection includes: `pattern_type`, `severity` (critical/high/medium), chunk `id`, character offset
- [ ] Detected items with severity = critical or high trigger automatic redaction before LLM submission
- [ ] Redacted tokens are replaced with `[REDACTED:<type>]` placeholders
- [ ] Detection scan completes within 200 ms for a 32 000-token context window
- [ ] All detections are recorded in the execution trace for audit
