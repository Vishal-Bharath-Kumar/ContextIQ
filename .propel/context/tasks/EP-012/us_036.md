## Story

**As a** DevOps/SRE,
**I want** all ContextIQ services to expose Prometheus-scrapable RED metrics (Rate, Error, Duration),
**So that** I can monitor platform health and set up alerting thresholds.

## Acceptance Criteria

- [ ] Every service exposes `/metrics` endpoint in Prometheus text format
- [ ] Core metrics include: `contextiq_requests_total`, `contextiq_request_duration_seconds`, `contextiq_errors_total`, `contextiq_active_requests`
- [ ] All metrics are labeled with: `service`, `endpoint`, `intent_type`, `tenant_id`
- [ ] Grafana dashboard "ContextIQ Platform Overview" is provisioned via ConfigMap (6 panels: RPS, latency p50/p95/p99, error rate, active requests)
- [ ] Prometheus retention is 15 days for raw metrics
- [ ] Alert rules for: error rate > 5%, p95 latency > 3 s, and connector failure rate > 10% are defined in a PrometheusRule resource
