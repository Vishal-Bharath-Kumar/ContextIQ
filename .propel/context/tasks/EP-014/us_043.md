## Story

**As an** enterprise administrator,
**I want** ContextIQ to authenticate users through our corporate identity provider (Entra ID, Okta, or Auth0),
**So that** employees can log in with their existing corporate credentials and we do not manage a separate user directory.

## Acceptance Criteria

- [ ] Keycloak is deployed in HA mode (2+ replicas) with a PostgreSQL backend
- [ ] Identity brokering is configured for at least one external IdP (Entra ID via OIDC)
- [ ] Users authenticating via the external IdP receive a Keycloak-issued JWT accepted by the MCP Gateway
- [ ] Group-to-role mappings from the external IdP are synchronized to Keycloak roles on login
- [ ] Keycloak admin UI is accessible to users with `ADMIN` role at `/auth` path
- [ ] Token lifetimes: access token = 5 min, refresh token = 8 h
- [ ] SAML 2.0 federation is supported as an alternative to OIDC for on-prem IdPs
