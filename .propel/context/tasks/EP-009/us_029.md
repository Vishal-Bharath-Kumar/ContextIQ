## Story

**As a** software developer,
**I want** ContextIQ to expand my context by traversing the knowledge graph to find related entities,
**So that** my AI assistant can surface upstream dependencies, owning teams, and related incidents without explicit queries.

## Acceptance Criteria

- [ ] Knowledge Graph Agent executes Cypher traversal starting from entities identified in ranked context
- [ ] Traversal follows edges: `DEPENDS_ON`, `OWNED_BY`, `HAS_INCIDENT`, `DEPLOYED_BY`, `REFERENCES`
- [ ] Traversal depth is bounded at 3 hops by default (configurable)
- [ ] Graph results are appended to `ranked_context` with a `source: knowledge_graph` label
- [ ] Traversal completes within 500 ms for graphs up to 1 million nodes
- [ ] Graph-expanded context does not exceed the remaining token budget from the execution plan
