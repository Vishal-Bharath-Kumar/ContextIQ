## Story

**As a** platform engineer,
**I want** all services to obtain short-lived database credentials from HashiCorp Vault rather than using static passwords,
**So that** compromised service credentials automatically expire and cannot be reused by an attacker.

## Acceptance Criteria

- [ ] Vault is deployed in HA Raft mode with 3 nodes; auto-unseal is configured via cloud KMS
- [ ] PostgreSQL, Redis, Neo4j, and Qdrant secrets engines are enabled and configured in Vault
- [ ] Services obtain database credentials via `vault agent` sidecar injection (Vault Agent Injector)
- [ ] Dynamic credentials have a 1-hour TTL and are renewed automatically by the agent before expiry
- [ ] Static credential rotation: any remaining static secrets are replaced during the initial Vault rollout
- [ ] Vault audit log is enabled and forwarded to the observability stack (Loki)
- [ ] Vault HA failover is tested: primary node failure results in < 30 s disruption
