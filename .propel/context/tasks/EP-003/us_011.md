## Story

**As a** software developer,
**I want** ContextIQ to ask me a targeted clarifying question when my prompt is ambiguous,
**So that** the retrieved context is relevant and I avoid wasting token budget on the wrong sources.

## Acceptance Criteria

- [ ] When intent confidence < 0.6, a clarification request is returned as a `clarification_needed` response
- [ ] Clarification message is concise (≤ 50 words) and includes one specific question
- [ ] Clarification response conforms to the MCP tool call response schema (not an error)
- [ ] User's clarification response is appended to context state and re-submitted through intent detection
- [ ] Second-pass intent classification after clarification receives the merged prompt
- [ ] Clarification round-trip is capped at 1 (no recursive clarifications)
