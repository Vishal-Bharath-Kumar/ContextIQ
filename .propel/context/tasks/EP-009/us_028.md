## Story

**As a** platform engineer,
**I want** the Knowledge Graph Agent to extract entities (services, repositories, developers, incidents) from indexed documents,
**So that** the graph captures the structural relationships in the enterprise engineering ecosystem.

## Acceptance Criteria

- [ ] Entity extractor runs as a post-indexing pipeline step triggered by `knowledge.chunk.indexed` events
- [ ] Extracted entity types: Service, Repository, Developer, Incident, Deployment, AlertRule, Document
- [ ] Each entity is created as a Neo4j node with properties: `entity_id`, `type`, `name`, `source_id`, `created_at`
- [ ] Duplicate entities are merged using a deterministic `entity_id` (source_type + canonical_name)
- [ ] Extraction completes within 500 ms per chunk on average
- [ ] Extraction errors are logged and the failed chunk is re-queued for retry
