## Story

**As a** software developer,
**I want** duplicate and boilerplate content (license headers, repeated imports, template scaffolding) removed from my context,
**So that** my AI assistant's context window is focused on meaningful content.

## Acceptance Criteria

- [ ] Rule-based deduplicator removes exact-duplicate chunks from the context set
- [ ] Common boilerplate patterns (license headers, auto-generated code headers) are identified via configurable regex rules
- [ ] Removed chunks are listed in a `removed_chunks` summary in execution state
- [ ] Deduplication reduces token count by at least 10% on typical enterprise codebases
- [ ] Processing completes within 100 ms for a context set of 50 chunks
- [ ] Original content is preserved in replay trace even when excluded from final context
