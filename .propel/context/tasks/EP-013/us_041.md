## Story

**As an** enterprise administrator,
**I want** a UI to register AI models, set routing weights, and view cost analytics per model,
**So that** I can optimize the model portfolio without modifying configuration files.

## Acceptance Criteria

- [ ] Model list page shows all registered models with provider, context window, cost per 1k tokens, latency tier, and active/inactive status
- [ ] "Add Model" form accepts: model ID (LiteLLM format), provider, context window size, cost, latency tier, and capability tags
- [ ] Model routing weights (quality, cost, latency) are editable per intent type via a slider UI
- [ ] Cost analytics panel shows last-30-day token spend per model with trend sparkline
- [ ] Model can be deactivated (immediately removed from routing candidates)
- [ ] Model changes are recorded in the audit trail
