## Story

**As a** software developer,
**I want** retrieved documents to be scored and ranked so that the most relevant context appears first in the AI prompt,
**So that** the AI assistant produces more accurate and focused responses.

## Acceptance Criteria

- [ ] Each document is scored using a combined weight: vector score (60%) + keyword score (20%) + recency (20%)
- [ ] Documents with combined score below a configurable threshold (default 0.5) are excluded
- [ ] Ranked list is truncated to fit within the allocated token budget from the execution plan
- [ ] Re-ranking step completes within 200 ms
- [ ] Final ranked list is stored in execution state as `ranked_context`
- [ ] Ranking weights are configurable per intent type via admin settings
