## Story

**As a** platform engineer,
**I want** the Intent Agent to produce a structured execution plan (which sources to query, token budget per source, ranking strategy),
**So that** the Retrieval Agent can execute efficiently without redundant lookups.

## Acceptance Criteria

- [ ] Execution plan is a structured JSON object stored in StateGraph state
- [ ] Plan specifies: `sources` (list), `token_budget` (per source), `ranking_strategy`, `cache_eligible` flag
- [ ] Token budget is allocated based on intent type and a total budget of 8 000 tokens by default
- [ ] Plan generation completes within 200 ms
- [ ] Retrieval Agent consumes the plan and respects its source list and budget limits
- [ ] Plan is stored in the execution trace for replay and audit
