## Story

**As a** platform engineer,
**I want** the MCP gateway to validate a JWT bearer token on every inbound connection,
**So that** only authenticated users and service accounts can invoke ContextIQ tools.

## Acceptance Criteria

- [ ] Requests without an `Authorization: Bearer <token>` header receive HTTP 401
- [ ] Tokens with invalid signatures are rejected with HTTP 403
- [ ] Expired tokens are rejected with HTTP 401 and a `WWW-Authenticate` header
- [ ] Valid tokens are verified against the Keycloak JWKS endpoint
- [ ] Token subject and roles are injected into the request context for downstream RBAC checks
- [ ] Token validation completes within 50 ms (JWKS cached locally with 5-minute TTL)
- [ ] Authentication failures are logged with user-agent, IP, and timestamp for audit
